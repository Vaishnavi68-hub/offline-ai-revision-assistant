# Offline AI Revision Assistant

An AI-powered study assistant that converts PDF study material into
summaries, flashcards, quizzes, and personalized revision plans.

## Project Status

🚧 Currently under development.

## Planned Features

- PDF upload and text extraction
- AI-powered summarization
- Topic extraction
- Flashcard generation
- Quiz generation
- Student performance tracking
- Weak-topic detection
- Personalized revision
- Local LLM support
- LLM model benchmarking
